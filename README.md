# 🌾 CropInsight India

> Full-stack data science project analysing Indian agriculture crop production (1997–2015).  
> Includes EDA, hypothesis testing, Random Forest regression, and an interactive React dashboard.

---

## Tech Stack

| Layer | Tech |
|---|---|
| Data Analysis | Python · pandas · NumPy · SciPy · scikit-learn |
| Notebook | Jupyter |
| Backend API | FastAPI · uvicorn · joblib |
| Frontend | React 18 · Vite · Recharts |

## Dataset

**Indian Agriculture Crop Production** — Kaggle  
Search: `Indian Agriculture Crop Production abhinand`  
Place `crop_production.csv` in the `data/` folder.

| Attribute | Detail |
|---|---|
| Records | ~246,000 |
| Period | 1997–2015 |
| Columns | State, District, Crop, Season, Area (ha), Production (tonnes) |

## Setup & Run

### 1 · Install backend dependencies

```bash
cd backend
pip install -r requirements.txt
```

### 2 · Run the analysis notebook

Open `notebooks/CropInsight_Analysis.ipynb` in Jupyter and run all cells.  
This generates `model/rf_model.pkl` and `model/encoders.pkl`.

```bash
jupyter notebook notebooks/CropInsight_Analysis.ipynb
```

### 3 · Start the backend

```bash
cd backend
uvicorn main:app --reload
```

API runs at `http://localhost:8000` · Docs at `http://localhost:8000/docs`

### 4 · Start the frontend

```bash
cd frontend
npm install
npm run dev
```

App runs at `http://localhost:5173`

## Features

### Dashboard
- 5 KPI stat cards (records, states, crops, production, yield)
- Top 10 states by production (horizontal bar chart)
- Season-wise production share (pie chart)
- Yearly production trend 1997–2015 (line chart)
- Top 10 crops by production (bar chart)

### EDA Explorer
- Average yield over time
- Area cultivated trend
- Mean/max yield by season
- Top 15 states and crops comparison

### Predict Yield
- Select state, season, crop, area, year
- Calls the FastAPI endpoint
- Displays predicted production (tonnes) and yield (t/ha)
